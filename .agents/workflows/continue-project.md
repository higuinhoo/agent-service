# Continuar o projeto

1. Execute `pwsh scripts/project-status.ps1`.
2. Leia apenas a tarefa ativa e o handoff se houver trabalho interrompido.
3. Use `docs/START_HERE.md` para carregar uma única skill e os arquivos relevantes.
4. Verifique afirmações do handoff por busca/diff/teste direcionado.
5. Execute a menor próxima fatia verificável com um agente por padrão.
6. Não promova tarefa ou decisão sem autorização.
7. Atualize somente estado/tarefa/handoff que realmente mudou.
