# Preparar handoff do projeto

Prepare a troca para outro agente sem iniciar trabalho novo.

1. Inspecione o diff e rode somente verificações relevantes.
2. Atualize `STATUS.md` e `TASKS.md` apenas se o estado mudou.
3. Registre somente decisões explicitamente aprovadas.
4. Substitua `HANDOFF.md` por objetivo, mudanças, arquivos, testes, riscos e próximo passo — sem histórico narrativo.
5. Responda com mudanças, arquivos, testes e pendências.
